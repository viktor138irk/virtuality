Как создать машину

  1. Скачайте установочный образ системы (.iso) на сайте разработчика — например, Ubuntu Server.
  2. Откройте Образы ОС и перетащите файл в окно загрузки.
  3. Нажмите Создать машину, выберите образ и конфигурацию.
  4. Когда задача завершится, нажмите «Открыть экран» и установите систему как на обычный компьютер.
{{ icon('globe') }}

Как открыть сайт или SSH из интернета

  1. Откройте Сеть и доступ.
  2. В блоке «Открыть доступ» выберите машину и сервис, например «Сайт (HTTPS)».
  3. Нажмите «Открыть доступ». Теперь адрес {{ host_ip }}:порт ведёт в машину.
  4. Если не открывается — нажмите «Проверить» рядом с правилом: панель подскажет, в чём проблема.
{{ icon('monitor') }}

Экран машины

  • Экран открывается в новой вкладке браузера — это как монитор, подключённый к машине.
  • Если курсор «застрял» внутри экрана, нажмите Ctrl + Alt.
  • После установки системы извлеките установочный диск на странице машины → «Диски и загрузка».
{{ icon('power') }}

Выключение и автозапуск

  • Выключить — аккуратно завершает работу системы, как кнопка питания.
  • Выключить принудительно — мгновенно, как выдернуть шнур. Используйте, только если машина зависла.
  • Автозапуск — машина сама включится после перезагрузки сервера.
{{ icon('cpu') }}

Сколько ресурсов выделять

  • Мини (1 ядро, 1 ГБ) — VPN, роутер, небольшие сервисы.
  • Стандарт (2 ядра, 4 ГБ) — сайт, база данных, Linux-сервер.
  • Мощная (4 ядра, 8 ГБ) — Windows, 1С, игровые серверы.
  • Процессор и память можно поменять позже, когда машина выключена.
{{ icon('wrench') }}

Если что-то не работает

  • Проверьте раздел Сервер — там видно, чего не хватает.
  • Посмотрите Задачи — у каждой есть подробный журнал.
  • Полная диагностика в терминале сервера: sudo vhealth.
